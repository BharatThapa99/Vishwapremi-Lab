Install once. Open the app. Start your lesson.

Vishwapremi Lab has two Windows applications: Teacher for the teacher's computer and Student for each lab computer. Both installers contain their own runtime. No Python, separate .NET installation, browser dashboard, internet account, or subscription is required.

Version 1.0 supports connection status, classroom notices, opening lesson websites, and locking Windows sessions. Website/game blocking, screen viewing, and a tamper-resistant background service are not included. This is a supervised classroom pilot.

1 · Set up the teacher computer

  1. Run Vishwapremi-Teacher-Setup.exe in the Windows account teachers will use. Keep the desktop shortcut and startup options selected.
  2. Open Vishwapremi Teacher. Create a teacher password with at least 12 characters. Store it with the school, accessible to authorized staff.
  3. Click Allow lab connections. Approve the Windows administrator request. This adds restricted firewall rules for encrypted TCP control and UDP discovery from the local subnet. They work whether Windows labels the school network Public or Private.
  4. Use a trusted lab network. Do not forward ports 8765 or 8766 on the router.

2 · Connect each student computer

  1. In Teacher, click Add computer. Name the first PC LAB-01. Only active network adapters are shown; the selected address is used as a fallback.
  2. Save its .vplab pairing file to a USB drive. The file works once and expires after 24 hours.
  3. On LAB-01, sign in to the Windows account students normally use. Run Vishwapremi-Student-Setup.exe. Keep automatic startup selected.
  4. Open Student, click Import pairing file, and select LAB-01's file. Student automatically discovers the teacher whose secure identity matches the file; there is no need to try several IP addresses.
  5. Wait for Connected to the teacher. The PC should appear online in Teacher within a few seconds.
  6. Repeat for LAB-02 to LAB-08, with a separate file for each PC. Delete the used files from the USB drive after confirming pairing. Keep the teacher app's password private.

Accounts matter: this release installs and saves pairing per Windows account. If a PC has several student Windows accounts, each needs its own installation/pairing and teacher entry. Do not pair everything while signed in as an administrator if students later use a different account.

3 · The daily teacher routine

  1. Turn on the teacher computer and sign in to Windows. Open Teacher and enter the teacher password. The controller starts after sign-in.
  2. Students sign in to their usual Windows account. Their connections start automatically.
  3. Click Select online, or tick individual PCs. Choose Open lesson website, Send a notice, or Lock computers.
  4. Check Recent classroom activity. Executed means the student app invoked the action. A browser launch does not guarantee a website loaded, and a displayed notice does not prove it was read.
  5. Use Lock teacher app when stepping away. Closing a window keeps the app running in the notification area beside the Windows clock. Right-click its icon and choose Exit to stop it.
Lock computers locks Windows. Students need to sign back in to Windows to resume. There is no remote unlock or teacher-controlled screen freeze in this version. Save student work before using this feature.

If something does not connect

Waiting for the teacherTeacher is on, signed in, and its controller says it is running. Install version 1.1 on both PCs and click Allow lab connections again. Both PCs must be able to reach each other on the local network.
Teacher still not discoveredOpen the router settings and disable AP isolation, client isolation, wireless isolation, or guest-network isolation for the lab. These router features deliberately prevent computers on the same Wi-Fi from communicating.

File used, expired or revokedIn Teacher, select and remove that PC's entry, then Add computer again and import the new file. Use this also if enrollment was interrupted after the teacher accepted it.

Expired actionDelivery timed out after 60 seconds without acknowledgement. It might have run if its acknowledgement was lost. Reconnect and check the PC before sending it again.

School handover and maintenance

  • Train at least two staff members using this guide. Keep one designated teacher Windows account and share the app password only with authorized teachers. Individual teacher roles and named audit trails are not implemented.
  • School configuration is under %LOCALAPPDATA%\VishwapremiLab. Close both apps before backup. Certificates and student credentials are encrypted to the Windows user; copying these files to another account or computer does not transfer their identity. A new controller needs fresh pairing.
  • There is no in-app password recovery in this release. Record the teacher password securely. If lost, an administrator can move the Teacher data folder aside with the app closed and start fresh, but all PCs must be paired again.
  • Uninstall from Windows Settings → Apps. This removes the app, shortcuts, and its sign-in startup entry. Configuration remains for reinstalling under the same Windows account. No automatic data deletion is performed.
  • The teacher's manually approved firewall rule remains after uninstall. If retiring the system, the administrator can remove the rule named Vishwapremi Lab Teacher in Windows Firewall.
  • These installers are not digitally signed. School IT should review and approve them before deployment. They do not download updates automatically; publish and reinstall a new release to update the included runtime.
  • The student application runs in the signed-in user's session and can be stopped by that user. It is not a Windows service, kiosk, or enforcement boundary. Restrict student administrator rights and plan application/network policies separately.

Test two PCs before all eight

Install on the teacher and two student PCs. Verify pairing, a notice, a harmless lesson website, Windows lock/sign-in, reconnection after reboot, and operation by a second teacher. Confirm that closing the student window leaves it connected and that Exit disconnects it. No school PCs were configured during the build.

Requirements: Windows 10 22H2 or Windows 11, 64-bit x64; a reachable school LAN; an administrator available for the teacher firewall rule. Internet is needed only for lesson websites. The installer and pairing workflow can run offline.
